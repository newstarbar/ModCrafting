# ModCrafting Fabric v0.2.1

本版本把 ModCrafting 从单个 Fabric 模组开发扩展到**整合包创作、求解与导出**。仍然只做创作与导出，不内置启动器、账号或下载管理。

`v0.2.0` tag 的 Release 工作流在验证阶段失败，未发布任何资产；`v0.2.1` 修复了干净 Windows runner 上的两个测试环境问题（缺少 `temp/` 目录与 golden 夹具被检出为 CRLF），功能内容与 0.2.0 候选一致。

## 本版重点

- **双源发现**：从想法生成结构化意图，检索 Modrinth 与 CurseForge（无 CurseForge Key 时自动降级并给出修复指引），输出候选评分、覆盖度、缺口与 nearMiss 报告。
- **通用底座**：按目标版本选择性能、画面、操作类模组，拒绝改变原版玩法的分类、纯服务端项与互斥组合；NeoForge/Forge 目标使用可用替代或明确标记缺口。
- **确定性求解与锁**：BFS 依赖闭包，产出 `DECLARED_INCOMPATIBLE`、`MISSING_DEPENDENCY`、`PINNED_VERSION_UNAVAILABLE` 等可操作 finding；`pack.lock.json` 固定版本与哈希，同一输入产生字节一致结果。
- **导出**：`.mrpack` 与 Prism/MultiMC 实例目录；`redistributable=false` 的条目只写引用、不内联字节，无法合法直链时给出明确警告。
- **桥接 Mod**：生成可编译的 Fabric 桥接工程（入口点、适配器、Mixin 配置、构建脚本），不修改第三方 jar。
- **分级改造 L1–L4**：L1 资源/数据覆盖与 L2 伴生 Mixin 工程默认可用；L3/L4 必须许可证允许修改且逐次确认，拒绝与回滚同样写入 `.modcrafting/transform-audit.jsonl`。L3 只产出补丁计划，L4 只产出类/资源清单，不伪造“已修改”。
- **工作台**：三栏 shell（导航、工作区上下文、主栏），新增实例 scope 与 Discover、Pack、Baseline、Bridge、Transform 面板，统一空态与错误态；移动端导航由同一注册表生成。
- **MCP**：新增整合包发现、工作区、求解、底座、导出、桥接与改造工具，总计 43 个。
- **CLI 修复**：Windows 上委托宿主自带 CLI 时改用 `cmd.exe` 调用，避免 Node 24 的弃用警告污染 `--json` 错误输出。

## 下载与安装

- **一句话安装（推荐）**：`npx -y github:newstarbar/ModCrafting#v0.2.1 install --auto --json`
- **Qoder 桌面版**：下载 `ModCrafting-Fabric-Qoder-Plugin-v0.2.1.zip`，在 Qoder Plugin 管理界面导入。
- **Codex / Claude Code / Qoder CLI**：下载 `ModCrafting-Fabric-Multi-Host-v0.2.1.zip`，按压缩包内的 README 与宿主目录配置。
- **仅 MCP / 仅技能**：`ModCrafting-MCP-v0.2.1.zip`、`ModCrafting-Skills-v0.2.1.zip`。
- **离线安装**：`ModCrafting-Offline-v0.2.1.zip`，解压后双击 `install.cmd`，或把包内 `PROMPT.md` 发给 Agent。
- **校验**：`ModCrafting-Fabric-SHA256SUMS-v0.2.1.txt` 包含全部资产与构建信息的 SHA-256。

## 验证范围与边界

- 发布前验证：`pnpm run typecheck`、`pnpm test` 366/366、`pnpm run cli:test` 58/58、43 个 MCP 工具协议 Smoke、离线 Fabric-Bench、Windows x64 / Observer V2 候选构建与 7 个 Release 资产打包。
- 未验证：真实 Modrinth/CurseForge 网络调用、真实 Gradle 编译生成的桥接/伴生工程、Minecraft 实机玩法、Prism/MultiMC 真实导入、Qoder 登录聊天。这些不能由离线 Smoke 或构建成功替代。
- 本版不包含字节码引擎或反编译器；需要真正改字节时优先使用 L2 伴生 Mod 或外部受信任工具，并继续受许可证与再分发约束。
